# Grading Sheet

## Rubric (per question)

| Level | Meaning | % of the question's points |
|---|---|---|
| **Excellent** | Correct, explains *why*, connects it to their own code | 100 % |
| **Good** | Correct, small gaps, needs a follow-up question | 75 % |
| **Basic** | Partly correct or needed the hint | 50 % |
| **Weak** | Mostly wrong, but shows some idea | 25 % |
| **None** | No answer / completely wrong | 0 % |

## Grade scale (100 points)

| Points | Grade (German scale) |
|---|---|
| 95–100 | 1.0 |
| 90–94 | 1.3 |
| 85–89 | 1.7 |
| 80–84 | 2.0 |
| 75–79 | 2.3 |
| 70–74 | 2.7 |
| 65–69 | 3.0 |
| 60–64 | 3.3 |
| 55–59 | 3.7 |
| 50–54 | 4.0 |
